# AI use

ISEF 2027 (Rules for All Projects, Eligibility 8): AI "may be used as a resource but must be cited and given proper acknowledgment"; a student "may not use generative AI to write the research plan, abstract, poster or to create citations". Journals (JEI, JOSS, IEEE) also ask for an AI-use statement.

Fill this in yourself, accurately. It protects you: judges ask, and an honest answer is never a problem; a hidden one can disqualify the project.

|---|---|---|
| Project idea and research questions | | |

| Experiments and analyses (`research/`, `emotif/audit.py`) | | |

| References | Not used to create citations; I checked each in the original | |
| Paper draft | Produced a first draft for my mentor | Rewrote it in my own words |
